# Datasets

Ce répertoire contient des exemples de jeux de données PDIPR utilisées pour travailler à la création du standard.
Il recense des jeux de données disponibles en open data et des jeux de données fournis par les membres du groupe de travail PDIPR.

* Le dossier [datasets open data](datasets_open_data) contient les jeux de données disponibles en opendata;
* Le dossier [datasets autre](datasets_autre) contient les jeux de données fournis par les membres du groupe de travail PDIPR.
